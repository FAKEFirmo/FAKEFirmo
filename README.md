## Hi I'm Federico 👋

I'm a student at Politecnico di Milano studying engineering of computing systems. I've always loved engineering and working with numbers and I'm sure this will not change anytime soon.

## What I'm building

Colibri is a study companion for Linear Algebra and Geometry that runs entirely on your own computer, with no Internet.
- A Local Language Model explains
- Math is done with exact code, never from the model
- Animated lessons in the terminal, shown step by step 
- Exercises that are generated and graded by code, and notes written straight into Obsidian.

Tested on Linux and macOS at every change, and sandboxed: the model has no network access (unless given access to it).

## What i care about
- Local-first and private: the data stays on the machine unless said otherwise.
- Correct before clever: if a number matters, code computes it and a test checks it.
- Tools that teach: software that helps you visualize a concept, not just get an answer.
